# 倍轻松

（20分钟左右）

  1. 自我介绍
  2. 是否在职，目前薪资
  3. ArrayList 和 LinkedList 的区别是什么？
  4. 给一个场景：插入一个百万的数据或者千万的数据，用ArrayList快还是LinkedList快？（这个被整懵逼了）
  5. 给一个场景：一个List中已经存储了一些元素，现在有另一个元素，怎么判断列表中是否有这个元素？（我回答是for循环遍历，面试官说使用contains）
  6. 现在有一个字段 scope，要实现它的排序，应该怎么做？（回答用orderSet）那怎么实现自定义排序？（用Comparator接口或Comparable接口）
  7. 给一个场景：现在有100个线程执行任务，需要他们执行任务完成后拿到进行统计，应该怎么做？（只回答了用Future类和有同步方法，这里应该用CountDownLatch才对）
  8. 现在有一个订单表中有一个字段uid，现在要计算订单大于1的用户id，写出它的sql。（这应该是很容易的一道题，当时大脑有点宕机了，竟然没说出来）
  9. 项目是怎么导出接口的？（Yapi，EasyYapi）
  10. 目前做过多少个接口？（回答没具体去数）多少个Controller？（回答5、6个，其实说少了很多，这里只说了兽用工作站的，实际应该接触过很多）
  11. git常见命令？
  12. rebase是什么命令？
  13. 公司项目是怎么构建部署的？（Jenkins自动化流水线）
  14. 反问：你有什么问题吗？（问了公司的技术栈，主要是使用spring cloud；部门的业务稳定吗？是作为支撑部门的；什么时候知道面试结果？三个工作日内）

# 涂鸦智能

（总共30-40分钟）

  4. 算法平时在项目中有用到吗？

  7. Java的内存模型是怎么样的？（听成了Java内存区域，回答错了）
  8. 了解哪些垃圾回收方式？（我只回答了垃圾回收算法，没有回答垃圾回收器，怕挖坑）

  10. Redis有哪些持久化方式？
